## 数据红线（写文档时）

1. 分数只引用「本次会话内真实跑过」的前后值，不做跨会话基线混比；
2. 「检测到但修不了」必须明说（重复对 → 剩余债务 → clone-refactor 路径）；
3. 所有 model id / key 相关表述以 `probe/result.json` 为准，不硬编码；
4. 每张表的数据都能追溯到本表列出的文件路径。
